# 🛡️ Cyber Crime Dashboard

A SOC-style cybersecurity monitoring dashboard developed using Python, Flask, HTML, CSS, and JavaScript.

This project simulates real-world cybersecurity monitoring by combining:

* Port scanning
* Packet sniffing
* Log analysis
* Real-time alert monitoring
* Threat visualization

The dashboard helps detect suspicious activities such as:

* Brute-force attacks
* Suspicious traffic patterns
* Open ports
* Malicious network behavior

---

## 🚀 Features

* 🔍 Port Scanner
* 📡 Live & Offline Packet Sniffing
* 📄 Log Analysis
* 🚨 SOC-style Real-time Alerts
* 🔔 Alert Sound Notification System
* 🌐 Network Traffic Monitoring
* 📊 Cybersecurity Dashboard UI
* 🌙 Dark/Light Mode
* 🔐 Login & Authentication System
* 🧠 Basic Threat Detection Visualization
